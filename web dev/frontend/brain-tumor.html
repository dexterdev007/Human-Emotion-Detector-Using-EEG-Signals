Brain Tumor Theory (Complete)

End-to-end explanation of MRI tumor detection aligned with your project workflow, dataset, and model stack.

Problem Definition

Goal: classify brain MRI scans into four categories: glioma, meningioma, pituitary, and no tumor. This module compares classical ML models and deep learning models in one interface.

Dataset and Class Labels

  • Source: Brain Tumor MRI Dataset (Kaggle path provided by you).
  • Classes: glioma, meningioma, pituitary, no_tumor.
  • Input images are resized to a fixed shape before model training.

Preprocessing Theory

  • Image resizing standardizes dimensions for all models.
  • Pixel normalization scales values for stable optimization.
  • Augmentation improves generalization (rotation, zoom, brightness).
  • Optional localization helps focus on tumor-relevant region.

Model Theory in This Module

  • Logistic Regression: fast linear baseline classifier.
  • SVM (RBF): margin-based nonlinear separator.
  • Random Forest: ensemble of decision trees.
  • CNN: learns spatial filters from MRI patterns.
  • ResNet50: deep residual architecture for robust features.

Evaluation Metrics

  • Accuracy: overall correct predictions.
  • Precision: how many predicted tumors are correct.
  • Recall (Sensitivity): how many real tumors are detected.
  • Specificity: how well non-tumor cases are identified.
  • AUC: class separability across thresholds.
  • Confusion Matrix: class-wise error analysis.

Deployment Logic in This UI

  • Upload MRI image and extract compact image features.
  • Run all 5 models and get class probabilities.
  • Compute final class by majority vote + confidence summary.
  • Display full model-wise probability table for transparency.

Clinical Interpretation

The model output is a screening aid, not a final diagnosis. Radiologist review and multimodal clinical context are required for treatment planning.
